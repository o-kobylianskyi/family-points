## Delivery scope
1. Native Kotlin/Jetpack Compose day/week/month calendar (not WebView) showing workspace-scoped, server-generated TASK/REWARD_WINDOW events with filters and navigation. Follow user-approved Soft Family light/dark references and existing i18n.
2. Preserve task occurrence identity `definitionId:date:slotKey`, avoid duplicate slot actions and distinguish virtual PLANNED from a persisted TaskInstance. Server-managed rights decide who can view/start/manage tasks.
3. Rewards show scheduled upcoming windows and availability/unmet reasons, next opening in workspace timezone; purchase is attempted online and server authoritative for schedule/prerequisites/points/cooldown/quotas.
4. Add native reward schedule editor only for accounts with management permission, after Backend confirms DTO/endpoints. Keep existing reward conditions and request workflow intact.
5. Cache calendar/reward projections scoped by account+workspace+member+date range; offline display **read-only**, clearly stale/offline; no offline time-reward purchase or local bypass of new schedule. Do not attempt a speculative point debit or offline task start here; see IMP-0005.
6. No new app control or timed entitlement enforcement in this package; a reward purchase window is not app-usage control.
