- A: two members (owner/non-owner); parent+child MemberGroups; group membership, delegated role where supported; WorkNode hierarchy; private template with customized title; task definition, schedule slot, execution with owner/member mapping; reward definition, request and purchase; ledger positive+negative adjustment, zero and nonzero balance; custom currency; media asset with exact bytes, SHA256 and binding to group/task/reward; settings.

Persist canonical digest of *every* B family-owned row + global accounts/auth/catalog/security audit. Record A canonical rows including original/mapped FK graph; counts alone are **not** sufficient.
- File: real AES-GCM portable .fpbackup generated by application exporter, saved and read back from disk. Use immutable snapshot/operation UUID, source epoch, schema revision and checksum. Do not put keys/passwords/real child data into logs.
- Explicitly document which records the exporter currently does *not* support; absent categories must yield BLOCKED, not simulated green coverage.
